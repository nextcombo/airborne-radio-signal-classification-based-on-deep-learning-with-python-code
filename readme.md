# Airborne Radio Signal Classification Based on Deep Learning [with Python Code]

Introduction: Rapidly understanding and labeling radio spectrum in an autonomous manner is a key factor for spectrum interference monitoring, radio malfunction detection, dynamic spectrum access, opportunistic mesh networks, and numerous regulatory and defensive applications. Condensing complex high-data-rate radio frequency information floods into precise and accurate tags allows for compact operations and transmissions, which are critical components in many radio sensor and communication systems today. For years, the classification and modulation recognition of radio signals has been accomplished through meticulously crafted feature extractors tailored to specific signal types and attributes, and by deriving compact decision boundaries from them using decision boundaries derived from analysis or statistical learning boundaries within low-dimensional feature spaces.
Over the past five years, we have witnessed rapid disruptions based on improved neural network architectures, algorithms, and optimization techniques, collectively referred to as deep learning (DL) [26]. Recently, in the fields of computer vision, speech, and natural language processing, DL has replaced state-of-the-art machine learning (ML); in these domains, feature engineering and preprocessing were once crucial topics that allowed for cleverly designed feature extraction and transformation to manageable reduced-dimensional representations, where labels or decisions could be easily learned from this representation with tools such as support vector machines or decision trees. Among these widely used frontend features, there are scale-invariant feature transform (SIFT) [9], bag-of-words [8], Mel-frequency cepstral coefficients (MFCC) [1], and other widely relied-upon features, but they no longer require today's state-of-the-art performance.
Due to the learning capabilities of large neural network models with a large number of free parameters discovered recently, the feature learning capability based on raw high-dimensional input data directly targeting advanced supervised objectives has significantly improved. This is a result of the combination of powerful regularization techniques [18], [21], significantly improved stochastic gradient descent (SGD) methods [15], [16], low-cost high-performance graphics processing unit capabilities, and key neural network structure innovations such as convolutional neural networks [5] and corrected linear units [13]. It was not until Alexnet [14] that many of these technologies were combined to achieve several orders of magnitude increase in model size, parameter count, target dataset complexity, and task complexity, bringing direct feature learning from images to the state of the art. At this point, the trend in machine learning has been relentless, replacing rigidly simplified analytical features and models derived from end-to-end feature learning with more accurate high-degree of freedom (DOF) models. These models come from data using end-to-end feature learning. This trend has been proven in visual, text processing, and speech domains but only recently has it been widely applied or fully realized on radio time series datasets.
In our work [30], [32], we pointed out that these methods can be easily applied to simulate radio time series sample data, allowing for excellent performance in classifying radiation source types, achieving an equivalent accuracy that is several times higher than the best practice method based on high-order moments for feature-based classification currently available. In this work, we provide a wider range of additional radio signal types datasets, more realistic simulations of wireless propagation environments, new datasets with airborne measurements (i.e., actual propagation effects), significantly better new methods for signal classification than our initial introduction, and an in-depth analysis of many real engineering designs and system parameters affecting the performance and accuracy of radio signal classifiers.
Dataset generation: We generated a new dataset for this survey based on the improved version of tools described in [29]. Utilizing 24 different analog and digital modulators, we covered a wide range of single-carrier modulation schemes. In the context of this work, we considered several different propagation scenarios, firstly several simulated wireless channels generated from the model shown in Figure 2, and secondly clean air (OTA) transmission channels without channel impairments as shown in Figures 3 and 4. The digital signal was shaped by a raised cosine pulse shaping filter with a roll-off value range (α).

We consider two different compositions of the dataset, first a general dataset consisting of 11 classes that are relatively low information density and typically found in damaged environments. In most cases, these 11 signals represent a relatively simple classification task under high signal-to-noise ratios, somewhat similar to standard MNIST digits. Secondly, we introduce a "difficult" dataset containing all 24 modulation types. These include many higher order modulations (QAM256 and APSK256), which are used in real-world scenarios for very high signal-to-noise ratios and low fading channels, such as in pulsed satellite links [25] (e.g., DVB-S2X). However, we apply losses beyond what you would expect in this context and only consider relatively short observation windows for classification, where the number of samples (â‰) = 1024. Short-term classification is a challenging problem because the decision process cannot wait for additional data to increase certainty. In many real-world systems, this situation arises when processing short observations in the environment (e.g., when rapid scanners are used) or bursty short messages. Under these influences, in low signal-to-noise ratios (from -20 dBc/N0 to +30 dBc/N0), one would not expect to achieve near 100% classification rates across the entire dataset, making it an excellent benchmark for comparison and future research.
Consider the following specific modulations for both data sets:
- Normal classes: OOK, 4ASK, BPSK, QPSK, 8PSK, 16QAM, AM-SSB-SC, AM-DSB-SC, FM, GMSK, OQPSK
- Difficult classes: OOK, 4ASK, 8ASK, BPSK, QPSK, 8PSK, 16PSK, 32PSK, 16APSK, 32APSK, 64APSK, 128APSK, 16QAM, 32QAM, 64QAM, 128QAM, 256QAM, AM-SSB-WC, AM-SSB-SC, AM-DSB-WC, AM-DSB-SC, FM, MSGK, OQPSK.

A. Airborne Data Acquisition
In addition to simulating wireless channel impairments, we have also implemented an OTA testbed where we use a generic software radio peripheral (USRP) [19] B210 software defined radio (SDR) to modulate and transmit signals. We use the second B210 (with an independent free running LO) to receive these transmissions in the laboratory through a relatively benign indoor wireless channel on the 900 MHz ISM band using a second B210 (with an independent free running LO). These radios use the AD9361 [35] RFIC as their radio front end with an LO, frequency (and clock) stability of about one millionth (PPM). We tune the signal to about 1 MHz to avoid DC signal damage associated with direct conversion but store the signal at baseband (offset only by LO error). The received test transmission is stored unaltered alongside the ground truth labels from the transmitter.
Conclusions: The DL method continues to show great potential in improving the sensitivity and accuracy of radio signal identification, especially in short observation periods. We have demonstrated that deep networks are becoming increasingly effective when utilizing the depth residual architecture, and we have shown that well-trained deep networks can effectively use OTA data through air transmission, with an accuracy loss of about 7% on datasets or directly and effectively train using OTA data if there is sufficient training data. Although it is currently difficult to obtain labeled large datasets for such tasks, and channel models are also challenging to match with actual deployment conditions, we have quantified the practical requirements for managing datasets and training regimes for such systems, and helped quantify the performance impact of doing so.
Regarding how best to manage datasets and training regimes for such systems, there is much more to learn. However, we have demonstrated in this work that our methods perform similarly to those on synthetically generated datasets at high Signal-to-Noise Ratio (SNR) OTA datasets, which is a significant step towards real-world application. We have shown that transfer learning can be effective but cannot achieve the same performance as direct training on very large datasets. As simulation methods improve and our ability to match synthetic datasets with real-world data distributions increases, this gap will narrow. When real data capture and labeling become difficult, transfer learning will become an increasingly important tool. The performance tradeoffs demonstrated in this work help clarify these key parameters in data generation and training, and hopefully aid in increasing understanding and focusing future efforts on optimizing such systems.
